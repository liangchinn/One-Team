# 拾光教學｜One Team

一個為 VEX GO 教學團隊設計的教學知識與師資培訓工作台。整合教案、共備會議、觀議課紀錄和教師培訓旅程，讓每一次教學實踐都能被團隊累積與傳承。

## 本機預覽

```bash
node server.js
```

接著開啟 `http://localhost:4173`。

## 功能原型

- 教學團隊總覽與活動動態
- 正式教案、共備會議及觀議課入口
- 新進教師的階段式培訓旅程
- 團隊培訓進度與成長指標
- 響應式桌面及行動裝置介面

## 帳號與資料

- 管理員：`admin`／`0000`（管理員姓名：彭彭）
- 其他夥伴可直接使用電子信箱註冊
- 帳號、教案與觀議課資料儲存在伺服器的 `data/db.json`（首次啟動時自動建立）
- 密碼使用 PBKDF2 加鹽雜湊保存，不會以明碼寫入資料庫

伺服器第一次啟動時會自動建立管理員。如果既有資料庫中沒有管理員，也會在啟動時自動補建。需要重新設定管理員時可執行：

```bash
npm run admin:reset
```

預設會將彭彭的密碼重設為 `0000`；正式上線時可使用 `ADMIN_PASSWORD="新密碼" npm run admin:reset` 指定新密碼。

進入網站時會先顯示登入頁。使用 `admin`／`0000` 登入後，左下角會顯示「彭彭／網站管理員」，登出後才會回到登入頁。GitHub Pages 預覽也支援這組管理員帳號；正式多人共用與跨裝置資料同步則應部署 Node.js 伺服器。

## 分享給團隊

網站監聽 `0.0.0.0` 並支援環境變數 `PORT`，可部署至支援 Node.js 與持久化磁碟的服務。部署後將服務提供的 HTTPS 網址分享給團隊即可。正式上線後請立即修改預設管理員密碼，並備份 `data` 目錄。
